# RocoPilot 0.5.1.0

> 本版本由社区 fork（Mshenchen/RocoPilot）基于 dev 分支构建，延续自原上游仓库。

## 🎉 特性：

- **灵动的血脉展示**：奇遇战斗识别到血脉后，灵动岛战斗流程详情会显示「精灵：xxx · 血脉：xxx」，未识别时不显示。
- **血脉识别日志**：血脉提示识别成功时输出日志，便于核对识别结果与排查问题。

## ✨ 优化：

- **奇遇解除识别提速**：第一回合敌方血条呈 10% 解除形态时，通过模板识图（截图主循环逐帧检测）判定奇遇解除，不再依赖 1 秒一拍的 OCR 循环，第一回合内即可稳定命中并按设置的解除操作执行。
- **入场期横幅扫描**：战斗入场过渡（状态未识别）阶段，后台 OCR 每轮只并行识别血脉与异色两个横幅区域，入场即解除的奇遇不再因横幅早于战斗场景确认而漏识别。

## 🔧 修复：

- **奇遇解除判定**：修复入场时敌方血量已为 10%（奇遇已解除）却仍按普通战斗释放技能导致击败精灵的问题；该场景下现在会正确执行「奇遇解除操作」（无操作 / 回能 / 捕捉），并计入奇遇统计。
- **捕捉结算**：捕捉结算改为周期点击关闭奖励弹窗，修复结算阶段卡住的问题。

## ⚠️ 注意：

- 原上游仓库（FelixHenrikChristian/RocoPilot）已删除；应用内更新器仍指向原作者的更新源，可能无法检查更新，请以本仓库 Release 页为准手动更新。
- 识别敌方血条需要 `battle-enemy-health` 识别区域配置，当前提供 2048x1152（16:9 全系）与 1920x1440（4:3 估算值）两份；4:3 分辨率如识别异常，请在区域编辑器中校准。
